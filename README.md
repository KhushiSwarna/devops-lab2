# DevOps Lab 2 - Containerization & Kubernetes Orchestration

## Objective

To containerize a sample application using Docker and deploy, scale, update and automate it using Kubernetes and Jenkins.

## Technologies

- Docker
- Docker Compose
- Docker Hub
- Kubernetes
- Minikube
- kubectl
- Jenkins
- Python Flask
- Ubuntu WSL2

## Workflow

GitHub → Jenkins → Kubernetes → Deployment → Pods → Service

## Docker Experiments

- Dockerfile and image build
- Container lifecycle management
- Image tagging and Docker Hub push
- Docker Compose
- Named volumes
- Bind mounts
- Docker networking

## Kubernetes Experiments

- Deployment and Service manifests
- Multiple replicas
- Scaling
- Rolling updates
- Rollback
- Continuous Deployment using Jenkins
